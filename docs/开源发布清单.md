# GitHub 开源发布清单

## 可以提交

- `src/`、`electron/`、`public/`、`scripts/`：应用源代码
- `cloudfunctions/`、`cloudbase/`：旧版企业 WPS/CloudBase 兼容代码和数据库结构
- `package.json`、`pnpm-lock.yaml`、`vite.config.*`、`tsconfig*.json`
- `README.md`、`SECURITY.md`、`docs/`
- `.env.example` 和 `cloudbase.json`：只包含配置模板和环境变量占位符

## 不要提交

- `.env`、`.env.local` 或任何包含真实值的环境变量文件
- 真实工作记录 Excel、导出的 Markdown 年度报告、个人配置 JSON 和图片
- `node_modules/`、`dist/`、`release/`、`*.tsbuildinfo`
- WPS 登录缓存、CloudBase 控制台截图、访问令牌和客户端本地数据

## 发布前检查

1. 运行 `pnpm test` 和 `pnpm build`。
2. 用 `git diff --cached` 检查暂存区，不要只检查工作区。
3. 确认 `git status --ignored` 中个人文件被忽略。
4. 在一台没有本地配置的新电脑上验证：可以跳过 WPS 登录并导入 Excel；个人 WPS 登录不会依赖维护者的密钥。
5. 为仓库选择并提交一个明确的开源许可证。若希望别人自由使用、修改和分发，通常可以考虑 MIT；许可证选择应由项目作者确认。

## 推荐的首次提交

```powershell
git init
git add .
git status --short
pnpm test
pnpm build
git commit -m "Initial open-source release"
```

确认暂存内容没有个人文件后，再在 GitHub 创建空仓库并添加远程地址：

```powershell
git remote add origin https://github.com/<你的用户名>/<仓库名>.git
git branch -M main
git push -u origin main
```
