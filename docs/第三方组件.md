# 第三方组件

Windows 客户端会在构建阶段从金山文档官方 CDN 下载固定版本的 `kdocs-cli`，并通过 SHA-256 校验后放入安装包。

- 组件：`kdocs-cli`
- 当前构建版本：`2.5.29`
- 官方来源：[kdocs-app/kdocs-skill](https://github.com/kdocs-app/kdocs-skill)
- 下载地址基址：`https://wpsai.wpscdn.cn/skillhub/pro`
- 二进制文件不提交到 GitHub；`scripts/fetch-kdocs-cli.cjs` 会在打包时自动获取。

`kdocs-cli` 负责个人 WPS 云文档登录、搜索和下载。它的登录凭据仍由组件自己保存到当前用户的系统凭据存储中，不会写入本项目源码、安装包或 GitHub。

如需重新分发客户端，请同时核对官方组件的当前服务条款和分发政策；如果官方来源或许可发生变化，应停止内置下载并改为引导用户从官方渠道安装。
