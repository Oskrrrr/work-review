# 工作脉络 1.0.0

这是工作脉络的第一个正式版本，基于 0.8.0 完成本地复盘体验、导出内容、应用图标和桌面客户端体验的收尾优化。

## 相比 0.8.0 的新增功能

- 长期工作前台的“跨年度长期事项”区域支持展开/收起，默认展开，状态保存到本地。
- 新增“软件信息”页面，包含版本、发布者、功能概览、隐私说明和项目入口。
- 导出年度 Markdown 文字稿时固定输出六个章节：数据概览、长期工作项目、已确认事项与阶段性工作、未串联的单项工作、完整工作时间线、给 AI 的写作提示。

## 相比 0.8.0 的修复

- 修复没有长期项目时阶段性事项和单项工作被遗漏的问题。
- 修复空数据集导出文字稿结构不完整的问题。
- 修复长期、阶段性和未串联记录在文字稿中重复或遗漏的问题。
- 修复 Electron `file://` 环境下应用图标引用为根路径，导致侧栏和软件信息页出现破损图片的问题。
- 修复软件信息页版本变量在生产构建中未替换，点击页面后出现空白的问题。
- 优化图标在侧栏小尺寸下的显示效果。

## 桌面客户端与视觉更新

- 使用新的“工作脉络” 1024×1024 Windows 应用图标。
- 同步更新 Windows 安装包、快捷方式、网页 favicon 和 PWA 图标。
- 安装包标准命名为 `work-review-1.0.0-windows-x64-setup.exe`。
- 发布者元数据统一为 `Oskrrrr`。
- 配置了正式 Windows 代码签名入口；当前未内置证书，正式签名需要通过 `CSC_LINK` 和 `CSC_KEY_PASSWORD` 提供受信任的 Authenticode 证书。

## 验证结果

- 单元测试：21 个通过，1 个跳过。
- Vite 生产构建通过。
- Electron Windows 便携版构建通过。
- Windows NSIS 安装包构建通过。

本版本没有改变原始 Excel/WPS 云文件，也不会自动把工作记录发送给 AI 服务。
